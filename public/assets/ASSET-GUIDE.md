# V2 Asset Guide

## Brand
- `brand/logo-mark.png` — peeking Jace + K? mark; transparent.
- `brand/icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png` — install assets.

## Jace
- `jace/stickers/*.png` — 512px transparent expression assets.
- `jace/mini/nav.png` — optimized small Ask Jace navigation sticker.
- `jace/mini/chat.png` — chat avatar.
- `jace/mini/message.png` — daily-message treatment.
- `jace/avatar/jace-avatar.png` — profile/identity treatment.

Use Jace Yellow only for Jace-specific interactions and emotional moments. Do not use these stickers as generic decoration.

## Navigation & subjects
Custom SVG files are under `icons/navigation` and `icons/subjects`.

## References
`references/v2-phase1-brand-board.png` is the visual direction board and is not intended to be rendered in the production UI.
